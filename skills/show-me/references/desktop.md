# Desktop Evidence

Use when a desktop app window is the clearest proof of behavior.

Good fits:

- macOS, Electron, or native desktop apps
- windows, dialogs, preferences, notifications, and visible error states
- UI changes where layout, copy, controls, theme, or app chrome matter

Prefer a focused app-window screenshot. Do not use a full-desktop screenshot
when a focused window capture is possible.

## Capture Guidance

- Make the target window visible, frontmost, and unobstructed.
- Wait until the requested state has finished rendering.
- Include enough window context to identify the app.
- Avoid unrelated windows, notifications, and private content.

## Proof Quality

Strong proof shows the requested app state clearly.

Weak proof is clipped, hidden, still loading, too broad, or only shows startup
when the requested behavior is deeper in the app.
